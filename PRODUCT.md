# Product

## Platform

web

## Stack
React (TypeScript), Vite, Tailwind CSS, Framer Motion, Lucide Icons

## Users
Data engineers, platform architects, system evaluators, and engineering teams building, operating, or inspecting real-time streaming event pipelines.

## Product Purpose
StreamForge is a real-time event streaming and operational intelligence platform. It ingests high-volume events, processes and validates them with fault-tolerant pipelines, persists clean structured data, and delivers live operational monitoring and business insights.

## Positioning
An end-to-end, fault-tolerant event streaming architecture featuring at-least-once delivery, idempotent database storage, dead-letter queue isolation, and real-time operational intelligence — turning continuous raw events into trustworthy actionable insights.

## Operating Context
A high-converting, interactive landing page that showcases StreamForge's capabilities. Features a live simulated dashboard with real-time ticking metrics, animated SVG area charts, a pipeline health donut gauge, a 4-stage pipeline overview (Ingest, Process, Store, Analyze), and an interactive end-to-end architecture visualizer (Event Generator → Kafka → Stream Processing → PostgreSQL → Analytics & Dashboard).

## Capabilities and Constraints
- Pixel-perfect alignment with the approved visual reference design.
- Warm cream background canvas with organic ambient peach/amber gradient waves.
- Elevated pillowed white cards with multi-layered soft ambient shadows.
- Interactive live simulation mode: live event counters, pulsing real-time SVG area chart, live pipeline health breakdown.
- Interactive architecture diagram with animated signal pulses traveling between components.
- Responsive layout across desktop, tablet, and mobile viewports with clean accessibility.

## Brand Commitments
- Brand name: StreamForge (with stylized dynamic orange waveform icon).
- Palette: Warm cream ground (`#FAF7F2`), radiant brand orange (`#EA580C`, `#F97316`), deep slate charcoal headings (`#111827`), soft warm gray body text (`#4B5563`), emerald green for live health (`#10B981`).
- Typography: Clean geometric sans-serif with crisp hierarchy and balanced line lengths.
